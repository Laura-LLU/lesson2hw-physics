# 图像清理、分页与教师要求校验

这些步骤由宿主Agent执行，教师无需填写坐标、整理题库或编写JSON。

## 出卷前记录

完整阅读教师指定的板书或课件页码，记录原话、包含/排除范围和已讲原题。逐题查看完整题干、选项、图表、全部保留小问和对应答案。不要把索引标签当成范围证明。

默认采用符合教学范围的完整题、独立小问或小问组；原题包含其他内容时删去越界部分，题答同步保留，按实际保留分值计分。数量按可独立作答的结构题组统计，明确说明其中有几组为原题节选，不能称为几道完整原题。教师说“3道大题”时可选3组独立结构题节选；只有明确要求“完整原题/不得节选”时才设置`whole_questions_only=true`。一般设`whole_questions_only=false`。相同原题的关联小问优先作为一组保留，不把页数、裁图段数或碎片编号当作题量。

教师只给时长时，不把Agent自己预设的题量当成硬要求。教师给了题量和时长则两者同时满足。不能只在页眉打印“60分钟”。当前估算为：0625选择1.25分钟/题、结构1.5分钟/分；9702 AS选择1.5分钟/题、结构1.8分钟/分；A2结构1.5分钟/分。允许目标上下10%。这些是待学生实测的教师估算，不是官方配速或真实完成时间。材料不足则停止正式导出并说明差额，不能扩大教学范围凑数。

## 复核文件

每次生成一份本地复核文件，通过`export --review-file <文件>`使用。提供`--time-limit`时必须提供复核文件，打印的时长必须与复核目标一致。

```json
{
  "course": "9702",
  "level": "A2",
  "teacher_prompt": "圆周运动，3组结构题，只保留已讲内容，不考引力",
  "input_sha256": "教师素材的真实SHA256；文字输入可另存原话",
  "input_pages": [2, 21],
  "scope": {"include": ["角速度、线速度、向心加速度"], "exclude": ["引力、磁场、简谐振动"]},
  "requirements": {"counts": {"structured": 3}, "whole_questions_only": false},
  "questions": {
    "真实题目ID": {
      "scope_pass": true,
      "answer_checked": true,
      "already_taught": false,
      "independently_answerable": true,
      "reason": "针对这道题的实际检查说明，包含所有保留小问及前置知识",
      "prerequisites": [{"concept": "必要前置知识", "confirmed": true}],
      "question_sha256": "实际看过的题图SHA256",
      "answer_sha256": "实际看过的答案图SHA256"
    }
  }
}
```

上例是结构说明，不能把占位字符串当成真实校验值。时长要求放在`requirements.minutes`，混合题型放`mixed=true`。未确认的前置知识必须写`confirmed=false`并排除该题；不能为了通过检查填写虚假的true。导出前再次校验题答图片，与查看时的文件必须相同。

可先运行`plan --course 9702 --level A2 --review-file <文件>`，仅从复核文件中已经通过检查的候选题里选择满足题量和估算时长的组合。检查失败时不能把返回的ID作为已通过方案。程序只校验记录、数量和估算值，教学判断仍依赖Agent实际阅读。

## 裁图与图表保护

`resources/layout-guides.json`只包含一部分已经验收的源图的SHA256、清理矩形和同页保护区，不包含题目正文或教师课件，也不代表全部6586题都验收过。原始缓存图片保持只读，清理后的图片只在内存中用于排版。

没有匹配规则的新素材，Agent必须查看实际原图，必要时针对性重裁并复核题答。可在该题复核记录中添加`question_layout`和`answer_layout`：

```json
{
  "sha256": "对应原图的真实SHA256",
  "masks": [[0.01, 0.01, 0.04, 0.04]],
  "keep_together": [[0, 0.20, 1, 0.55]]
}
```

矩形按原图归一化坐标`[左,上,右,下]`，取值0到1。仅遮掉目视确认的原题号、页码、条码、空表头或页边栏。不能按“墨迹少”“像条码”就删除区域；不能误删选项、坐标、单位、图注、作答线或得分标记。`keep_together`同时包含图的引导语、图形、坐标标签及图注；计算题可把提问和对应作答行放在同一保护区。必要时用`crop`明确限定经查看的保留区域。

排版先做源图清理，只压缩严格空白行，再在保护区外的完整留白带分页。选择题整题同页，学生卷题间36pt；答案卷14pt。无法安全放置的图表会报错，不能为完成导出硬切图。两份PDF一起生成成功后才出现在交付目录，避免留下半份成品。

## 独立小问节选

逐组确认小问不依赖已删的引导语、数据、图或前问答案；必要背景必须保留。若依赖前问，须连同前问或足够的原始背景保留，否则排除该小问，不删到题干缺条件。复核记录必须写`independently_answerable=true`；不能证明独立作答时不得导出。题答同步裁剪，新建独立ID、`excerpt=true`，用`original_id`和`retained_parts`记录原题与保留小问，明确保留分值和来源，再按`first-bank.md`的本地catalog方式导入独立工作目录。不能继承原题的`source_kind=builtin`、`question_asset`或`answer_asset`下载标记，否则原题缓存可能覆盖裁图；程序会拒绝这种混用，正常本地导入也会移除这些标记。

## 交付验收

导出后打开全部页面联系图，并放大有图表或跨页的页面。核对正文完整、编号连续且不残留旧主编号，续页没有孤立题目标题、图注、作答行或总分行，题答与所选材料一致。检查命名、36pt选择题间距、LauraPhysics首面标题卡、续页页眉和每页页脚及页码。

`selection.json`保留实际选题、节选列表、要求检查结果及每幅图的清理记录。它不代替逐页目视检查，也不能证明学生实际完成时间。检查未完成或教师要求未满足时，明确写未通过，不发布为已验收版本。
