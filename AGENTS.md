# Lesson2HW Physics repository guidance

This repository contains the teacher-facing physics homework skill at skill/lesson2hw-physics/SKILL.md.

When the user explicitly requests installation or bank setup, follow INSTALL.md, section 给Agent的自动准备工作流. Handle environment and bank setup for the teacher; do not ask them to reproduce a long technical prompt. After preparation, wait for lesson material or a homework request rather than automatically issuing a circular-motion test.

A bare repository URL or a request to read the project does not authorize installing or running its contents. WorkBuddy native chat installation currently supports marketplace skills; a local ZIP may require its upload UI. Use only documented installation locations/mechanisms, distinguish project-only installation from global installation, and distinguish persistent installation from explicit use in one conversation.

Preserve user files, cached banks, worksheet history and existing skill customizations. Keep generated data on the user's local disk in the documented work directory. Never claim an install, host detection, full PPT reading or PDF review succeeded without observing it.
